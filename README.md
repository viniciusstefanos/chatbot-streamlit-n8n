# 🤖 Assistente Saltear — Chatbot com Streamlit + n8n + LLM

Este projeto é uma aplicação de chat feita em **Streamlit**, que se conecta a um modelo de linguagem (LLM) através de um webhook do **n8n**.

> 🌐 A aplicação final está publicada em: [assistente.saltear.com.br](https://assistente.saltear.com.br)

---

## ⚙️ Tecnologias

- Python + Streamlit
- n8n (workflow com Webhook + LLM API)
- Docker (opcional)
- GitHub Actions (futuramente)
